## My Favorite Series: *Resident Evil* 🧟

**Resident Evil** is a survival-horror franchise that started as a video game by Capcom in **1996** and grew into movies, animated films, and TV series. The story follows survivors fighting the outbreaks caused by the ***Umbrella Corporation***, a powerful pharmaceutical company that secretly built deadly bio-weapons.

Learn more on the [official Resident Evil website](https://www.residentevil.com/) or the [Resident Evil Wikipedia page](https://en.wikipedia.org/wiki/Resident_Evil).

### Key Terms

The infection that started it all is the `T-virus`. In code, an outbreak check might look like this:

```python
def check_survivor(is_bitten):
    if is_bitten:
        return "Infected by the T-virus!"
    return "Still human. Keep running!"

print(check_survivor(False))
```
